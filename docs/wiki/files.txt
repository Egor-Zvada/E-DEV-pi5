ФАЙЛЫ С MAC / IPHONE

e-dev links → SMB-ссылка с текущим IP.
Mac: Finder → Перейти → Подключение к серверу → smb://<IP-Pi>/Share.
iOS: Файлы → меню → Подключиться к серверу → текущий IP Pi.
Пользователь выбран при установке, пароль SMB меняется в
Settings → Доступ и пароли → Файлы SMB.

Каталог на Pi: /srv/share. Это временный обмен фото/видео и файлами;
единственную копию важных фотографий храните отдельно от microSD.
Доступен из IN/OUT по IP, если доступ SMB включён.
