HYBRID — ПРЯМЫЕ ИСКЛЮЧЕНИЯ

e-dev settings → AP → Hybrid Settings

«Учёт RU IP-базы»: использовать российские IPv4-сети IPdeny.
«Ежедневное обновление»: скачивать базу автоматически.
«Обновить IP-базу сейчас»: загрузить вручную.
Последний рабочий кэш остаётся локально, при сбое загрузки не удаляется.
Без интернета классификация продолжает работать с сохранённой базой.

«Прямые домены»: добавить/удалить домен без https:// и пути;
правило включает поддомены. Начальные исключения включают .ru/.su/.рф
и вспомогательные домены Ozon, Wildberries, Госуслуг и 2ГИС.
«Прямые IP / сети»: публичный IPv4 или CIDR не шире /8.
«Проверить маршрут»: ввести домен/IP, увидеть IPv4, маршрут и причину.
Это проверка выбора маршрута, не доступности приложения.

При выключенном учёте RU-базы свои доменные/IP-правила остаются.
Все остальные назначения в HYBRID направляются через VPN.
Изменения применяются сразу; старые соединения могут требовать
переподключения. DNS задаётся в AP → DNS и общий для режимов точки.
TCP/UDP 53 перехватывается Pi. DoH/Private Relay обходят доменные
правила, но классификация по RU IP-базе и своим IP продолжает действовать.

Общие CDN-IP могут обслуживать разные сайты; зарубежные CDN российских
сервисов иногда требуют дополнительных исключений. Проверяйте адреса
конкретного сервиса. VPN-контейнеры идут целиком через общий туннель,
исключения HYBRID действуют только для OUT. Выбор VPN-сервера здесь
не меняется. В HYBRID при выключенном VPN DNS через туннель недоступен.
