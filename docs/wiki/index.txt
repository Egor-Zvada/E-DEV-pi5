E-DEV — справочник домашнего сервера
Egor Zvada • E-DEV • egor-zvada.ru

  e-dev status                 живой дашборд (q — выход, l — ссылки)
  e-dev status --once          короткий текстовый статус
  e-dev links                  актуальные панели и файлообмен
  e-dev wifi clients           число клиентов Wi-Fi, IP и MAC
  e-dev wifi status             точка, режим трафика, VPN-сервер
  e-dev wifi settings          меню подсети AP и DHCP
  e-dev lan setup              меню IN/OUT и резервных входов
  e-dev vpn on|off|status       включение и выключение самого туннеля
  e-dev vpn settings           меню выбора default / manual / auto
  e-dev vpn manual             меню выбора одного сервера
  e-dev vpn settings default   меню выбора основного и резерва
  e-dev vpn auto               включить Auto и измерить профили
  e-dev speedtest              скорость через активный VPN без переключения
  e-dev wifi hybrid settings   меню настроек гибрида
  e-dev passwd all             общий новый пароль сервисов

  e-dev help lan               интерфейсы, мост OUT и резервирование
  e-dev help panels            LXConsole и Incus UI
